# Decodificador de texto

Abra `index.html` no navegador. Digite letras minúsculas sem acento e espaços e escolha Criptografar ou Descriptografar. As chaves são: a → ai, e → enter, i → imes, o → ober e u → ufat.

Para copiar e colar automaticamente, use o projeto em um contexto seguro (HTTPS ou localhost) e conceda a permissão solicitada pelo navegador. Caso contrário, use Ctrl+C ou Ctrl+V manualmente. É possível iniciar um servidor local com `python3 -m http.server 8000` e acessar `http://localhost:8000`.

## Estrutura de pastas

- `index.html`: página principal
- `css/`: estilos
- `js/`: código JavaScript
- `img/`: imagens
